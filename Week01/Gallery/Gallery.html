Electric Billing System

The Electricity Billing Management System is a C-based software application designed to handle the billing process for electricity consumption automatically.

Smart Toll Plaza Management System

A Smart Toll Plaza Management System in C++ is an excellent object-oriented programming (OOP) project. It automates vehicle classification, calculates toll fees, processes smart electronic payments (simulating a FASTag/RFID system), tracks real-time revenue, and handles file-based data persistence.

Full Adder Circuit Design

Full Adder is a combinational circuit that adds three inputs and produces two outputs. The first two inputs are A and B and the third input is an input carry as C-IN. The output carry is designated as C-OUT and the normal output is designated as S which is SUM.

Solitrate Game

This project is a terminal-based clone of classic Klondike Solitaire written in Python. It manages core game logic including deck shuffling, tracking columns, card filtering rules, and game state updates. The code serves as a text-based foundational engine that can easily be upgraded into a full graphical user interface.

Digital Clock

This project is a lightweight desktop digital clock application built using Python's built-in Tkinter library. It dynamically fetches system time and updates a neon-styled LED text display every second using recursive event scheduling.

Brew & Cold Coffee App

This project is a visually striking, cross-platform mobile application built using Flutter and Dart designed for specialty coffee lovers. It features interactive animations to explore cold brews, customizable ingredient sliders, and a seamless state-managed cart system. The architecture relies on a clean, component-based widget tree that ensures high-performance rendering on both iOS and Android from a single codebase

Snake RL

Building a Snake game powered by Reinforcement Learning (RL) involves creating a standard Snake game environment and training an AI agent to play it using Q-Learning or Deep Q-Networks (DQN). The agent learns by trial and error, receiving rewards for eating food and penalties for hitting walls.

Naheed's Collection E-Commerce Website

Naheed Collection is a premium, multi-brand online e-commerce website that specializes in luxury embroidered clothing and South Asian designer wear for women. The platform acts as a digital marketplace, bringing together intricately designed unstitched fabrics and ready-to-wear silhouettes that highlight refined cultural craftsmanship like heavy threadwork, delicate lacework, and artful appliques.
